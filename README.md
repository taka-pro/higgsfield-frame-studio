# Frame Studio — Higgsfield API

人物と背景を選んで、キャラクターが動く・しゃべる動画を作れるWindowsアプリです。
行動と秒数を選ぶと、参照画像と生成プロンプトをHiggsfield APIへ送信します。コードやプロンプトを自分で書く必要はありません。

**アプリの利用に月額料金はありませんが、動画生成には利用者自身のHiggsfield APIキーとAPI残高が必要です。生成ごとにAPI利用料が発生します。** HiggsfieldのWebサービス用プランとは別のAPI用残高を使います。具体的な料金・割引・条件は公式サイトで確認してください。

## ダウンロードして使う

**[Windows版をダウンロード（Releases）](https://github.com/taka-pro/higgsfield-frame-studio/releases)** · [ソースコード](https://github.com/taka-pro/higgsfield-frame-studio)

1. 上記の **Releases** を開き、Assetsの `FrameStudio-win-x64.zip` をダウンロードします。
2. ZIPを右クリックして「すべて展開」。ドキュメントなど、書き込み可能な場所に展開してください。
3. 展開先の `FrameStudio/HiggsfieldStudio.exe` をダブルクリックします。
4. 「API設定」を開き、Higgsfieldでキーを作成した直後にコピーした **`ID:APIキー` の全文**を、一つの入力欄へ貼り付けます。
5. 人物・背景・モデル・行動・秒数を選び、「動画を生成する」を押します。
6. 完成した動画をアプリで再生できます。「フォルダを開く」で保存先を開けます。

**「Code → Download ZIP」は開発者向けのソースです。すぐ使いたい方はReleasesのアプリ用ZIPを選んでください。**
このREADMEを単体ZIP内で読んでいる場合も、上記リンクから最新版の配布ページを開けます。

### 動作環境

- Windows x64（64bit Intel / AMD CPU）向け。macOS・Linux・32bit Windows用ではありません。ARM64は未検証です。
- インターネット接続、Higgsfield APIキー、API用残高。
- .NETランタイムは配布ZIPに同梱しています。**.NET・Python・VS Codeのインストールや、事前のスクリプト実行は不要**です。管理者権限も通常不要です。
- 生成はHiggsfieldのサーバーで行います。ローカルでAIモデルを動かすためのGPUは不要です。
- 内蔵プレビューにはWindowsのメディア機能が必要です。
- 署名なしの試用版です。Windowsの保護機能が警告を表示する場合があります。入手元を確認し、組織の端末制限には従ってください。
- ZIP内から直接起動したり、exeだけを取り出したりせず、フォルダ全体を展開してください。

## できること

- 人物7枚・背景8枚のAI生成サンプルを同梱。自分のPNG/JPEG画像も追加できます。
- Wan 3.0、Seedance 2.5、MiniMax H3を選択。初期設定はWan 3.0です。
- 横長16:9、音声あり。Wan / Seedanceは720p、MiniMaxは2K固定。秒数はモデルの対応範囲で変更できます。
- セリフ・音楽アレンジを任意指定。顔・髪型・服装などを保つようプロンプトに指示します。

| 行動 | 空欄の場合のセリフ・音楽 |
| --- | --- |
| 振り返って挨拶 | 今日は楽しかったよ！ |
| 音楽に合わせてダンス | 明るいダンスポップ、約120 BPM、歌なし |
| 前かがみでコメント | ねえ、どうしたの？ |
| 近づいて笑いかける | セリフなし・環境音あり |
| 手を差し伸べて誘う | 一緒に行こう？ |

ダンス選択時は入力欄が「音楽アレンジ」に切り替わります。「サルサ音楽」「ゆったりしたジャズ」などを入力できます。他の行動では入力したセリフがデフォルトを置き換えます。長いセリフには十分な秒数を指定してください。生成結果には揺らぎがあり、同一性・発話・動作の完全な再現を保証するものではありません。

## 保存先とAPIキー

- 動画：アプリと同じフォルダの `output/` に自動保存。
- 受付記録：`.local/jobs/`。画面には今回の起動中の生成履歴だけを表示します。以前の動画はoutputに残ります。
- 任意のキー保存：`.local/api-key.bin`。Windows DPAPIで暗号化し、同じWindowsユーザーで復号します。保存しない場合は起動中のみ保持します。
- 保存チェックを外してAPI設定を適用すると、以前の保存キーも削除します。Higgsfield側のキー失効操作とは異なります。
- 同じ参照画像は起動中に再利用します。再起動・画像の内容変更・API設定の再適用時には再アップロードします。
- 配布物にAPIキー、利用残高、生成動画は含まれません。他人にフォルダを渡す際も `.local/` と `output/` は含めないでください。

ソースからの実行では、実行ファイルから最も近い祖先の `ref/` があるフォルダを作業ルートにします。配布版はexeの隣にrefを同梱するため、展開したFrameStudioフォルダ内へ保存します。

## 生成中・エラー時

- 「動画を生成する」で有料の生成を1回送信します。事前見積もりや金額上限機能はありません。残高・請求額は公式Billingで確認してください。
- 完了まで自動で状態を確認してダウンロードします。所要時間はモデル・尺・混雑などで変わります。
- 「状態確認を中断」はアプリの監視だけを止めます。サーバーでの生成はキャンセルしません。
- 起動中の履歴から「生成状態を確認」で取得を再開できます。アプリを閉じた後の未取得動画は公式コンソールで確認してください。
- 受付結果が不明な場合、重複生成を避けるため自動再送しません。公式コンソールのRequestsを先に確認してください。
- 再生できない場合は「フォルダを開く」から保存動画を別のプレイヤーで開いてください。
- 問題報告には操作手順、モデル、秒数、エラー文を記載してください。APIキーや未加工の履歴・署名URLは貼らないでください。

## 開発者向け

C# / .NET 8 / WPFで作成しています。コーディングはGPT-6 Astraを使用し、動作・セリフ・UIなどの希望を伝えて、実際の出力を確認しながら調整しました。Higgsfield公式の配布アプリではありません。

Windowsと.NET 8 SDKが必要です（配布ZIPの利用者には不要）。

```powershell
dotnet run --project src/HiggsfieldStudio/HiggsfieldStudio.csproj
dotnet run --project tests/HiggsfieldStudio.Tests/HiggsfieldStudio.Tests.csproj -c Release
```

テストはHTTPモックによるオフライン検証です。有料API生成は行いません。認証先の制限、画像再利用、生成受付、状態確認、ダウンロード、モデルごとのリクエストなどを検証します。

PowerShell 7で配布物を作成：

```powershell
pwsh -File scripts/Build-Release.ps1
pwsh -File scripts/Export-PublicSource.ps1
```

| フォルダ | 内容 |
| --- | --- |
| src/HiggsfieldStudio | WPF画面、キー保存、操作処理 |
| src/HiggsfieldStudio.Core | API通信、モデル設定、プロンプト組み立て |
| tests | オフラインテスト |
| ref | 配布可能なデモ人物・背景 |
| scripts | 固定名の配布ZIPと公開ソースの作成 |
| docs | プロンプト設計、公開手順 |

公開手順はソースに同梱した `docs/RELEASING.md` を参照してください。GitHub Actionsはビルド・検証を行い、手動実行時に配布ZIPを成果物として出力します。自動でReleaseを公開する処理はありません。
